# British Airways - Passenger Lounge Eligibility Analysis

Business operations analysis completed during the British Airways Job Simulation on Forage.

## Overview
* Structured lookup tables in Microsoft Excel to categorize flight schedules across short-haul and long-haul routes.
* Calculated customer lounge access percentages across Tier 1, Tier 2, and Tier 3 membership levels.
* Documented operational justification and policy recommendations.
